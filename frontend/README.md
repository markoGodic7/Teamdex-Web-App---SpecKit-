# TeamDex Frontend

This folder contains the Vite + React + TypeScript frontend for TeamDex.

Quick start:

```bash
cd frontend
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

Notes:
- Tailwind is configured via `tailwind.config.cjs` and `postcss.config.cjs`.
- Main entry: `src/main.tsx`.
- App root: `src/App.tsx`.
